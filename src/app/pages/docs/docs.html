Making Your First API Request

Creating and dispatching a request in OnSteroid is immediate. Launch either the Standalone Desktop App or the Web Client and click New Request:

  1. Select your HTTP verb (GET, POST, PUT, DELETE, PATCH).
  2. Enter your target endpoint URL (for example, https://jsonplaceholder.typicode.com/todos/1).
  3. Configure headers, query parameters, or JSON body fields in Monaco if needed.
  4. Click Send or press Ctrl + Enter.
// The response renders immediately in the Monaco viewer with HTTP status code, elapsed latency (ms), payload size, and formatted JSON.
02

Sandboxed Script Functions

All user scripts in OnSteroid execute safely inside an isolated iframe sandbox and are structured within enclosed asynchronous parent functions with explicit parameters injected by the runner:

Pre-Request Hook • preScript Runs before request dispatch 
// Pre-Request Hook (modify headers, body, or params directly):
async function preScript(headers, body, params) {
  headers["X-Request-Id"] = crypto.randomUUID();
  headers["X-Client-Time"] = new Date().toISOString();
  params["debug"] = "true";
}
Post-Response Hook • postScript Runs after response arrives 
// Post-Response Hook (read response headers, status, and payload):
async function postScript(responseHeaders, responseBody, headers, body, params) {
  console.log("Response received:", responseBody);
}
Test Runner Hook • testScript Assertions & boolean pass/fail 
// Test Script (receives status, timing, body & headers):
async function testScript(responseStatus, responseTime, responseBody, responseHeaders) {
  test("Response status is 200 OK", () => responseStatus === 200);
  test("Latency under 1.5s", () => responseTime < 1500);
  let passed = responseStatus === 200;
  return passed;
}
03

Custom Manual Encryption Scripting

When working with APIs that require bespoke payload encryption, hashing, or signatures, OnSteroid provides an enclosed encryptScript function runner:

  1. Navigate to the Encryption tab inside the Monaco request editor.
  2. Write your custom JavaScript logic inside the enclosed encryptScript(headers, body, params, encryptedHeaders, encryptedBodyPaths) function.
  3. Mutate the headers and body arguments directly.
  4. When you click Send, your encryption script runs first in the isolated sandbox before the HTTP request is dispatched.
Enclosed Encryption Function in Monaco Editor Pre-Dispatch Transformation 
async function encryptScript(headers, body, params, encryptedHeaders, encryptedBodyPaths) {
  // Compute custom hash / signature or encrypt sensitive fields:
  headers["X-Signature"] = "sig_" + btoa(JSON.stringify(body));
  if (body && body.sensitiveField) {
    body.sensitiveField = btoa(body.sensitiveField);
  }
}
04

Collection Import & Drag-and-Drop

OnSteroid supports three zero-friction import pathways to bring your existing API suites into your local workspace:

Drag & Drop .JSON

Drag and drop any OnSteroid capsule export JSON file directly onto the application window to parse capsules, requests, tests, and variables.

Swagger / OpenAPI URL

Open the Import tab, paste any public or internal Swagger UI / OpenAPI specification URL, and OnSteroid auto-generates paths, verbs, and sample payloads.

Shared Capsule Links

Paste a shared capsule URL or token from a teammate to synchronize endpoint groups and environment templates directly into your workspace.
