Custom Pre-Dispatch Scripting

Dedicated Manual Encryption Scripting Section

Real-world banking, enterprise, and payment APIs rarely fit into rigid, one-size-fits-all encryption checkboxes. Many gateways demand proprietary hashing, custom HMAC-SHA256 signatures, or selective field encryption.

Instead of locking you into predefined toggles, OnSteroid provides a dedicated Encryption Script Tab powered by Monaco. Write your custom encryption or signature logic manually in JavaScript — it runs right before the request is dispatched, mutating headers or payload properties exactly as your backend expects.

  • Per-field Monaco gutter lock icons (encryptedBodyPaths) and per-header lock toggles (encryptedHeaders) with Auto-encrypt
  • Direct programmatic access to mutate headers, body, and params
  • Dedicated Encryption Console tab in the Response Viewer for live cipher debugging

async function encryptScript(headers, body, params, encryptedHeaders, encryptedBodyPaths) {
  //only code written within this code block will be executed
  for (const path of encryptedBodyPaths) {
    body[path] = 'enc_aes256_' + btoa(String(body[path]));
  }
  for (const key of encryptedHeaders) {
    headers[key] = 'enc_hdr_' + btoa(String(headers[key]));
  }
  headers['X-Signature'] = customHmac(JSON.stringify(body), params.secretKey);
}

Script Automation

Dedicated Enclosed Script Functions

Every script in OnSteroid is written inside a clear, enclosed asynchronous parent function with explicit arguments passed in for headers, body, query parameters, and response data.

All user scripts execute inside an isolated sandbox iframe via asynchronous postMessage boundaries, guaranteeing that untrusted collection scripts can never compromise application state or leak local credentials.

  • Explicit parameter signatures for preScript, postScript, and testScript
  • Native boolean returns and integrated test(name, fn) assertion runner
  • Direct header and query parameter mutation before request flight
Instant Migration

Importing your API endpoints into OnSteroid takes seconds. Upload or drag and drop any OnSteroid capsule export JSON file directly into the app window, and the entire tree of capsules, requests, headers, variables, and scripts is parsed immediately.

  • Drag-and-drop support for OnSteroid JSON capsule exports and shared capsule links
  • Paste any Swagger / OpenAPI URL to auto-generate request capsules
  • Zero cloud uploads — files are parsed entirely in-memory on your machine

VS Code Power

Microsoft VS Code Monaco Editor Built-In

Editing deeply nested JSON bodies or complex scripts inside plain browser textareas is a recipe for syntax errors. OnSteroid embeds Monaco — the exact code editor engine that powers Microsoft Visual Studio Code.

  • Real-time syntax linting with inline error squiggles
  • Auto-format documents with a single shortcut (Shift+Alt+F)
  • Foldable JSON keys, bracket matching, and multi-cursor editing
